# Dynamic Programming

## Optimal Substructure

  

If path `a-b-e` is optimal from `a` to `e`, then subpath `b-e` must also

be optimal from `b` to `e`.

  
Formally, if

$$

C(a,e) = C(a,b) + C(b,e)

$$

  and $C(a,e)$ is minimal, then $C(b,e)$ must also be minimal.

  Not all problems have this property.

Example: finding the longest path from $a$ to $e$ (with no repeated

vertices) does **not** guarantee optimal substructure.

## Dynamic Programming (DP)

Dynamic programming combines **overlapping sub-problems** with **optimal substructure**.

- The term "programming" originally meant *planning*, not coding.

- "Dynamic" reflects **multi-stage planning**: choosing actions across

multiple time steps rather than a single static choice.

  

## Memorization

  

To avoid redundant computation, DP records the results of sub-problems.

  

This creates a memo table:

  

$$

f(x) =

egin{cases}

ext{compute and store if not already solved} \\

ext{reuse stored value otherwise}

\end{cases}

$$

  

## Bellman Equation

  

The Bellman recursion is at the heart of DP.

  

For cost-to-go (minimization):

  

$$

V(s) = \min_{a \in A(s)} \Big[ c(s,a) + V(\delta(s,a)) \Big]

$$

  

- $V(s)$: value function at state $s$\

- $A(s)$: set of actions available at $s$\

- $c(s,a)$: immediate cost of action $a$ in state $s$\

- $\delta(s,a)$: next state when taking action $a$ in $s$

  

## Value Function

  

The value function captures the best achievable performance.

  

Two forms:

  

**Cost-to-come:**

  

$$

J(x_k) = \min \sum_{i=0}^{k} c(x_i, u_i)

$$

  

**Cost-to-go:**

  

$$

J(x_k) = \min \sum_{i=k}^{N} c(x_i, u_i)

$$

  

where $c(x_i, u_i)$ is the stage cost at step $i$.

  

## Computational Complexity

  

- DP often reduces exponential brute-force complexity down to

polynomial.\

- However, it suffers from the **Curse of Dimensionality**:\

If state space size is $|S|$ and action space size is $|A|$, then

complexity can grow as:

  

$$

O(|S| \cdot |A|)

$$

  

Storage requirements can also become prohibitive.

  

## Value Iteration

  

Iterative update of the Bellman equation:

  

$$

V_{k+1}(s) = \min_{a \in A(s)} \Big[ c(s,a) + V_k(\delta(s,a)) \Big]

$$

  

Repeat until convergence:

  

$$

\| V_{k+1} - V_k \| < \epsilon

$$

  

## Extensions

  

**Stochastic cases (Markov Decision Processes):**

  

$$

V(s) = \min_{a \in A(s)} \Big[ c(s,a) + \sum_{s'} P(s'|s,a) V(s') \Big]

$$

  

**Continuous spaces:**\

Exact DP becomes infeasible → requires approximations (e.g., function

approximation, discretization).
